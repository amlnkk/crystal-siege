# Діаграма станів гри «Кристальна облога»

Автор: Аліна Мельник


```mermaid
stateDiagram-v2
    [*] --> Меню
    Меню --> Хвиля: натиснули "Старт"
    Хвиля --> Магазин: усі вороги мертві
    Хвиля --> Кінець: hp гравця <= 0
    Магазин --> Хвиля: натиснули "Наступна хвиля"
    Кінець --> Меню: натиснули "Ще раз"
```

## Пояснення станів

- **Меню**: початковий екран, кнопка «Старт».
- **Хвиля**: гравець б'є ворогів і збирає кристали.
- **Магазин**: між хвилями гравець купує захист за кристали.
- **Кінець**: гравець загинув, показуємо, скільки хвиль він пережив.

## Діаграма станів ворога

```mermaid
stateDiagram-v2
    [*] --> Появився
    Появився --> Переслідує: з'явився на арені
    Переслідує --> Атакує: гравець поруч
    Атакує --> Переслідує: гравець відійшов
    Переслідує --> Мертвий: hp <= 0
    Атакує --> Мертвий: hp <= 0
    Мертвий --> [*]: дати кристали гравцю
```

- **Появився**: ворог створений на краю арени.
- **Переслідує**: біжить до гравця.
- **Атакує**: б'є гравця, коли той поруч.
- **Мертвий**: зникає, гравець отримує кристали (правило з `pseudocode.md`).
