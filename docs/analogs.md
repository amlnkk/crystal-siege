# Порівняння з аналогами

Автор: Аліна Вознюк

Порівнюємо «Кристальну облогу» з двома іграми про хвилі ворогів: Vampire Survivors і Brotato.

| | Vampire Survivors | Brotato | Кристальна облога |
|---|---|---|---|
| Механіка | автоатака, гравець лише рухається | рух і стрільба по ворогах на арені | рух, удар з кулдауном, збір кристалів |
| Цикл | вбивай ворогів -> бери досвід -> обирай поліпшення | хвиля -> магазин -> сильніша хвиля | хвиля -> збір кристалів -> магазин -> сильніша хвиля |
| Що працює | швидкий початок, відчуття росту сили | рішення в магазині, вибір предметів | (перевіримо на прототипах) |
| Що не працює | з часом одноманітно, мало контролю | складно на старті, багато предметів | (перевіримо на прототипах) |
| Що беремо | постійне наростання хвиль | магазин між хвилями | і хвилі, і магазин |
| Чим відрізняємося | немає магазину | ресурси падають рівномірно | кристали лежать там, де небезпечніше |

## Висновки для нашої гри

1. Магазин між хвилями (як у Brotato) дає гравцю час на рішення, тому залишаємо його.
2. Наша унікальна ідея (кристали там, де більше ворогів) змушує йти на ризик, чого немає в аналогах.
3. Щоб не було одноманітно, як у Vampire Survivors, кожна хвиля має відчуватись інакше: більше ворогів, нові типи, міцніші.
