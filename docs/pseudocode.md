## 1. Спавн хвилі

```
На початку хвилі:
  номер_хвилі = номер_хвилі + 1
  кількість_ворогів = 5 + номер_хвилі * 3
  повторити кількість_ворогів разів:
      створити ворога на краю арени у випадковому місці
      hp ворога = 10 + номер_хвилі * 2
  створити кристали на арені (більше там, де більше ворогів)

Хвиля закінчується, коли всі вороги мертві → стан = "Магазин"
```

## 2. Удар і кулдаун

```
Кожен кадр:
  якщо гравець натиснув "атака" і cooldown == 0:
      створити удар перед гравцем
      cooldown = 0.5
  якщо cooldown > 0:
      cooldown = cooldown - час_кадру
```

## 3. Нагорода за ворога

```
Якщо hp ворога <= 0:
  стан ворога = "мертвий"
  кристали_гравця = кристали_гравця + 2
```
