# v1: гра «Кристальна облога» після зміни

Автори: Аліна Вознюк, Аліна Мельник, Софія Шкарбан

## Головна зміна (за спостереженням з проби)
Керування показано прямо в грі: у меню, постійною смугою внизу сторінки й банером над полем на початку першої хвилі (10 секунд).

Чому: під час проби з людиною поза командою (part2/03-outside-trial.md) тестувальниця не зрозуміла, як стріляти. У v0 керування було лише дрібним текстом під полем.

Прогноз: нова людина знаходить, як стріляти, за кілька секунд і без підказок.

## Інші зміни (без впливу на правила)
Новий вигляд: суворий кольоровий стиль, верхня панель, магазин списком, ефекти влучань. Механіка, числа й ціни ті самі, що в v0.

## Як відкрити
Завантажити три файли (index.html, style.css, game.js) в одну папку й відкрити index.html у браузері. Потрібні клавіатура й мишка.
