# v0: гра «Кристальна облога» до змін

**Дата фіксації:** 18.11.2026
**Автори:** Аліна Вознюк, Аліна Мельник, Софія Шкарбан


## Як відкрити
1. Завантажити три файли (`index.html`, `style.css`, `game.js`) в одну папку.
2. Відкрити `index.html` у браузері.

Також є онлайн-версія: https://amlnkk.github.io/crystal-siege/prototypes/03-scene/

## Середовище
- Браузер: 
- Пристрій: «ноутбук, Windows 11»
- Потрібна клавіатура й мишка. Телефон не підтримується, бо немає клавіш руху.

## Керування
- Рух: стрілки або WASD.
- Стрільба: пробіл (по найближчому ворогу) або клік мишкою (куди клікнули).

## Правила
- 6 життів у гравця, ворог має 2 життя (+1 за кожні 2 хвилі).
- У хвилі N кількість ворогів 5 + 3·N, купками по 2-4 на краях.
- Кулдаун пострілу 0.5 с.
- За вбитого ворога +2 кристали, підібраний кристал +1.
- Магазин: стіна 3, турель 5, швидкість 3, лікування 2.

## Відомі обмеження
- Немає звуку.
- Немає мобільного керування.
- Автоматично вибрану ціль іноді важко передбачити (стріляє по найближчому ворогу).
- Гру не перевіряли на різних браузерах і на слабких комп'ютерах.
- Тільки одна арена й один тип ворога.
